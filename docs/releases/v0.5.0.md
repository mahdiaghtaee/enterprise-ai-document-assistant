# v0.5.0 — Multilingual Quality Gates and Dependency Maintenance

Version 0.5.0 adds reviewed multilingual retrieval and grounded-answer quality evaluation while keeping the reference implementation on its existing .NET 8 architecture and security boundaries.

## Highlights

- Versioned English, Persian, and mixed English/Persian retrieval and answer datasets.
- Reviewer rationale plus explicit support, citation, and completeness judgments.
- Per-language and per-category Precision@K, Recall@K, MRR, and answer-accuracy reporting.
- Deterministic 95% bootstrap confidence intervals using a versioned fixed seed.
- Segmented CI thresholds so Persian or mixed-language regressions cannot be hidden by aggregate scores.
- Machine-readable multilingual evaluation artifacts retained by CI.
- Routine Python maintenance for Uvicorn and Ruff.
- Validated .NET OpenTelemetry minor/patch servicing while remaining on .NET 8.
- Refreshed .NET test dependencies within the existing major-version boundary.
- Dependabot policy now keeps semantic-major NuGet/Python upgrades deliberate and updates Python OpenTelemetry packages as a coordinated family.

## Validation

The release branch must pass the repository's complete validation matrix before publication:

- CI and .NET/Python tests;
- PostgreSQL integration;
- CodeQL and Dependency Review;
- Safe document-format integration;
- retrieval-quality evaluation;
- grounded-answer evaluation;
- multilingual quality evaluation;
- audit and observability integration;
- operational observability.

## Upgrade Notes

No database schema migration is introduced by the multilingual evaluation suite or the dependency-maintenance changes in this release. Existing installations should restore/rebuild application dependencies using the committed project and requirements files before redeployment.

The project remains on .NET 8. Major runtime and framework-adjacent package upgrades are intentionally tracked separately in issue #120 instead of being bundled into this release.

## Quality Boundary

The multilingual suite is a reviewed, deterministic synthetic regression suite. It is designed to detect repository regressions and compare committed behavior; it does not establish production-scale, population-representative, or provider-specific factual accuracy.

See `CHANGELOG.md`, `docs/MULTILINGUAL_EVALUATION.md`, and `SECURITY.md` for scope and limitations.
