# v0.5.1 — FastAPI compatibility and maintenance handoff

v0.5.1 closes the current active development cycle for Enterprise AI Document Assistant and moves the repository into maintenance mode.

## Highlights

- FastAPI upgraded from 0.115.6 to 0.142.1.
- Python OpenTelemetry maintained as a coordinated compatible family at API/SDK/exporter 1.45.0 and FastAPI instrumentation 0.66b0.
- Added request-validation and OpenAPI compatibility tests.
- Verified Docker/Compose startup and the full repository quality matrix after the FastAPI upgrade.
- Added explicit compatibility/rollback documentation.
- Recorded the completed reference boundary and deferred roadmap in `docs/PROJECT_STATUS.md`.

## Validation

The migration PR passed:

- CI and Python/.NET tests;
- Docker Compose build and health checks;
- PostgreSQL integration;
- Safe document format integration;
- audit and operational observability;
- retrieval, grounded-answer, and multilingual evaluation;
- Dependency Review;
- CodeQL for Python and C#.

## Maintenance boundary

No active feature roadmap is planned after this release. Major runtime migration, external identity lifecycle, production secret/encryption controls, production HA observability, OCR/layout expansion, and production-scale provider evaluation remain deferred until the project is intentionally resumed.
